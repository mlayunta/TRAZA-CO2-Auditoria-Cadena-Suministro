# TRAZA//CO2 — Auditoría Sostenible

Aplicación web profesional orientada a la evaluación de la sostenibilidad y eficiencia en la cadena de suministro, permitiendo el cálculo de indicadores clave de rendimiento (KPIs), el análisis mediante gráficos dinámicos y la generación de informes detallados en PDF.

## 📦 Características Principales
- **Auditoría por Procesos:** Entradas, pedidos, almacenaje, entregas, transporte, trazabilidad, logística inversa y responsabilidad social.
- **Gráficos Dinámicos:** Visualización en tiempo real mediante Chart.js (Gráficos de barras, radar y líneas de tendencias).
- **Adaptable por Sectores:** Ajuste automático de benchmarks según el sector (Retail, Gran Distribución).
- **Exportación a PDF:** Generación integrada de informes ejecutivos con jsPDF.
- **PWA (Progressive Web App):** Instalable en dispositivos móviles y de escritorio con soporte offline.

## 🛠️ Tecnologías Utilizadas
- HTML5 / CSS3 / JavaScript (ES6+)
- Chart.js
- jsPDF & jsPDF-AutoTable
- PWA (Web App Manifest & Service Workers)
